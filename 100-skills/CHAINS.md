# 교차 체인 · 카테고리를 넘나드는 체인 (정본)

> 팀 하나에 속하지 않아 `PLUGIN.md` 에 둘 수 없는 체인만 여기 적는다.
> **카테고리 체인 10종의 정본은 각 팀의 `100-skills/{팀}/PLUGIN.md`** (`chain` · `chain_steps` · `chain_desc`).
> `ROUTING.md` 의 체인 표는 이 파일과 PLUGIN.md 에서 **생성**된다 · `node scripts/build-routing.mjs`

| 체인 | 순서 | 무엇을 하나 |
|---|---|---|
| **VOC애널리틱스** | `006 → 078 → 020 → 054` | 리뷰 마이닝 → VOC 분류 → 개선 우선순위 → 리뷰 관리 |
| **브랜드셋업** | `081 → 082 → 008 → 012` | 브랜드 스토리 → 가이드라인 → 페르소나 → 가치제안 |

| **인플루언서캠페인** | `033 → 034 → 037 → 027` | 발굴·평가 → 계약·브리프 → UGC 활용 → 멀티채널 변환 |
