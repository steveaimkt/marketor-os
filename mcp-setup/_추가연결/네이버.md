## ⚠️ 먼저 · 네이버는 API 세계가 둘입니다

혼동하면 설치가 안 됩니다. **발급처가 아예 다릅니다.**

| | A. 데이터랩 (DataLab) | B. 검색광고 (SearchAd) |
|---|---|---|
| 무엇 | 검색어 트렌드 · 쇼핑인사이트 | 광고비 · ROAS · 키워드 성과 |
| 발급처 | `developers.naver.com` | `manage.searchad.naver.com` |
| 붙는 방식 | **공개 npm MCP** | **REST 서명 호출** (공식 MCP 없음) |
| 광고 계정 | 불필요 | 필요 |

A만 붙여도 [001][004][005][014] 는 실측으로 바뀝니다. B는 **광고를 실제로 집행 중일 때만** 값어치가 있습니다.

## A · 데이터랩 (약 3분)

### 1. 키 발급

1. `developers.naver.com` → 로그인 → **Application → 애플리케이션 등록**
2. 사용 API 에서 **「데이터랩(검색어트렌드)」 + 「데이터랩(쇼핑인사이트)」 둘 다 체크**
   - ⚠️ 하나만 체크하면 다른 쪽 호출이 403 으로 막힙니다
3. 등록하면 **Client ID · Client Secret** 이 나옵니다

### 2. `.env` 에 적기

```bash
NAVER_CLIENT_ID=발급받은_클라이언트_ID
NAVER_CLIENT_SECRET=발급받은_시크릿
```

### 3. MCP 로 등록하기

여덟 종과 달리 `.mcp.json` 에 미리 들어 있지 않으므로 **직접 추가**합니다. 클로드에게 이렇게 말하면 됩니다.

> "네이버 데이터랩 MCP 를 `.mcp.json` 에 추가해 줘. 패키지는 `naver-datalab-mcp-server` 이고, 키는 `.env` 의 `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET` 을 bash source 로 주입하는 방식으로."

손으로 넣고 싶다면 `.mcp.json` 의 `mcpServers` 에 이 항목을 더합니다. **키를 이 파일에 직접 쓰지 않는 것**이 요령입니다 (`.env` 를 읽어 넘깁니다).

```json
"naver-datalab": {
  "command": "bash",
  "args": [
    "-c",
    "set -a; source \"${CLAUDE_PROJECT_DIR:-$PWD}/.env\"; set +a; exec npx -y naver-datalab-mcp-server"
  ]
}
```

넣고 나면 **클로드 코드를 껐다 켭니다.** 그래야 새 연결을 읽습니다.

### 4. 되는지 확인

> "네이버 데이터랩으로 '마케팅 자동화' 검색 트렌드 뽑아줘"

시계열 숫자가 나오면 성공입니다.

- **되는 것**: 검색어 트렌드(시계열·성별·연령·디바이스) · 쇼핑인사이트(분야·키워드)
- **안 되는 것**: 광고 성과(ROAS·광고비). 그건 아래 B 입니다.

## B · 검색광고 (약 3분 · 광고 계정 필요)

공식 MCP 가 없어 REST 를 직접 부릅니다. 호출기는 `scripts/naver_searchad.py` 에 들어 있고 **의존성이 없어 따로 설치할 게 없습니다** (파이썬 표준 라이브러리만 씁니다).

### 1. 키 발급

1. `manage.searchad.naver.com` 로그인
2. **도구 → API 사용 관리** → 세 개를 받습니다
   - `API_KEY` (액세스 라이선스)
   - `SECRET_KEY` (`AQAA...==` 꼴)
   - `CUSTOMER_ID` (계정 번호 · 숫자)

### 2. `.env` 에 적기

```bash
NAVER_SEARCHAD_API_KEY=액세스_라이선스
NAVER_SEARCHAD_SECRET_KEY=비밀키
NAVER_SEARCHAD_CUSTOMER_ID=계정번호
```

### 3. 되는지 확인

```bash
python3 scripts/naver_searchad.py GET /ncc/campaigns
```

`HTTP 200` 이면 성공입니다. 결과가 빈 배열 `[]` 이어도 **인증은 정상**입니다 — 광고를 아직 집행하지 않은 계정이라는 뜻입니다.

## 막히면

| 증상 | 원인 | 어떻게 |
|---|---|---|
| 데이터랩 호출이 403 | 애플리케이션 등록에서 API 를 하나만 체크했다 | `developers.naver.com` 에서 나머지 하나도 체크 |
| 연결했는데 도구가 안 보인다 | 클로드 코드를 재시작하지 않았다 | 껐다 켠다 |
| `.env` 에 넣었는데 빈 값이라고 한다 | 터미널이 아니라 확장에서 실행 중이라 `export` 가 안 먹는다 | 위 JSON 처럼 **bash source 방식**으로 넣는다 |
| 검색광고가 401 | 키 세 개 중 하나가 다르다 | `CUSTOMER_ID` 는 숫자만 · 앞뒤 공백 확인 |
| 검색광고가 `[]` | 정상이다 | 광고 미집행 계정 · 인증은 통과한 것 |

## 안 붙이기로 했다면

그대로 두면 됩니다. 위 여섯 방법론은 전부 **`[추정]` 태그를 달고 완주**합니다. 추정치를 광고 입찰가 산정 같은 돈 쓰는 판단에 바로 쓰지만 않으면 됩니다.

CSV 로 대신할 수도 있습니다. 검색광고 관리자에서 성과 리포트를 내려받아 올리면 [042] 가 그 파일로 같은 분석을 합니다.
