# marketor-os · 마케팅 OS

> **AI 직원 53 + 방법론 100**으로 우리 회사에 맞는 마케팅팀을 구축하는 오픈 시스템

처음부터 다 쓰는 게 아니라, **조직을 진단하고 우리 회사에 맞는 팀으로 새로 짭니다.** 사람과 AI가 함께 일하는 하이브리드 마케팅팀을 구성하고, 필요한 스킬·도구는 더하고 안 쓰는 건 뺍니다. **MIT License**.

---

> **구조를 먼저 보시려면**: [구조.md](구조.md) 에 두 국면(팀 구축 전 · 구축 후)이 정리돼 있습니다.

## 어떻게 쓰나 · 3단계

| 단계 | 말할 것 | 어디서 | 끝나는 조건 |
|---|---|---|---|
| **1 · 구축** | **「팀 구축하자」** | 클로드 코드 | 편성안 승인 |
| **2 · 실행** | **「팀 실행하자」** | 클로드 코드 | 팀마다 첫 업무가 실제로 돌면 (대시보드도 여기서 뜹니다) |
| **3 · 운영** | 그냥 말하면 됩니다 | 대시보드 | 끝나지 않음 (「팀 피드백하자」 주간·월간) |

> **외울 문장은 이 3개가 전부입니다.** 나머지는 팀이 알아서 안내합니다.

> 설치 후 **「팀 구축하자」** 한마디면 시작됩니다. 승인 전에는 아무것도 바뀌지 않습니다.

## 뭐라고 말하면 되나 · 부를 말 454개

**명령어를 외우지 않습니다.** 스킬 100개마다 부를 말이 네댓 개씩 등록돼 있습니다. 전부 합쳐 454개입니다.

```
키워드 조사해줘        키워드 리서치 해줘      SEO 키워드 뽑아줘
검색 키워드 분석해줘    롱테일 키워드 찾아줘
```

다섯 문장이 전부 같은 곳으로 갑니다. 비슷하게만 말하면 됩니다.

| 찾는 방법 | 어디 |
|---|---|
| **전체 목록 (번호순)** | **[100-skills/ROUTING.md](100-skills/ROUTING.md)** · 100개 × 부를 말 전부 |
| 그냥 물어보기 | `뭐 시킬 수 있어?` |
| 카테고리별 | [100-skills/](100-skills/) 안의 `PLUGIN.md` |

**정확도는 재 봤습니다.** 실제 마케터가 쓸 법한 문장 596개를 던져 555개가 제대로 찾아갔습니다(93.1%). 재현하려면 `node scripts/eval-routing.mjs`.

### 그리고 멈춰 서는 자리가 32곳 있습니다

대외로 나가는 산출물 32개에는 발행 전 규제 검사가 걸려 있습니다. 표시광고법이 공통이고, 브랜드 프로필의 업종에 따라 화장품법·건강기능식품법 규정이 자동으로 갈아 끼워집니다. **검사를 통과하지 못한 산출물은 전달되지 않습니다.**

발송·발행·예산처럼 되돌릴 수 없는 일은 항상 ⏸ 로 멈추고 사람의 승인을 받습니다.

## 설치 (추천 · 명령 3줄)

전체 시스템(AI 직원 53 + 보관 14 + 방법론 100 + 대시보드 + 도구 가이드)을 통째로 세웁니다:

```bash
git clone https://github.com/steveaimkt/marketor-os.git
cd marketor-os
bash install.sh
```

`install.sh`가 전제 확인(node 20+·git·claude CLI) → 의존성 설치 → `.env` 준비 → 설치 검진까지 해 줍니다.
API 키는 지금 채우지 않아도 됩니다 · 비어 있으면 그 도구만 꺼진 채 동작합니다.

설치가 끝나면 이 폴더에서 `claude`를 열고 이렇게 시작하세요:

```
팀 구축하자
```

→ 조직을 진단하고 우리 회사에 맞는 팀을 구성합니다. 승인하면 **「팀 실행하자」**로 배선·시동까지 끝냅니다.

언제든 상태 점검: `npm run doctor` · 대시보드(일 시키기 화면): `npm run dashboard` → http://localhost:3737

### 플러그인으로 설치 (에이전트·스킬만 가볍게)

Claude Code 안에서 두 줄:

```bash
/plugin marketplace add steveaimkt/marketor-os
/plugin install marketor-os
```

> 플러그인 방식은 에이전트·스킬·온보딩만 설치됩니다. 대시보드·자동화까지 쓰려면 위 git clone 방식을 권합니다.

Claude Code가 없다면 먼저 설치하세요: https://docs.claude.com/claude-code

## 폴더 지도

폴더는 **배포 코어 / 로컬 전용 / 런타임** 세 층으로 나뉩니다. `git clone` 하면 **배포 코어만** 내려갑니다 (로컬 전용·런타임은 `.gitignore`로 제외).

### 🟢 배포 코어 — clone하면 이것만 (마케팅팀 구축에 필요한 전부)
```
marketing-os/
├── agents/         ← AI 직원 53 + 보관 14 · 팀 편성은 brand/dashboard.json > deptTeams
├── skills/         ← 재사용 스킬
├── mcp-setup/      ← MCP 12개 설치 가이드 (도구 연결)
├── mcp-servers/google-sheets/     ← 로컬 MCP 소스 (설치 시 npm install · 토큰은 각자 발급)
├── brand/          ← 회사별 설정 seam (org-map·roster·profile·marketer)
├── scripts/        ← 운영 스크립트 (+hooks = 예산·발행 승인 안전장치)
├── .mcp.json       ← MCP 설정 (env 참조 방식)
├── .claude-plugin/ ← 플러그인 매니페스트
├── CLAUDE.md       ← 프로젝트 헌법 (모든 에이전트 공통 규칙)
└── .env.example    ← API 키 템플릿
```
> `.claude/agents·skills·commands`는 위 폴더로의 **심링크**입니다 (Claude Code 규약 · 건드리지 마세요).

### ⚙️ 런타임 — 실행 시 자동 생성
```
└── node_modules/ (npm install)  ·  outputs/ (산출물)  ·  logs/
```

> 이 배포판은 위 **배포 코어**만 포함합니다. 운영자 내부 자산·교육/영상 도구·봇·자동화 같은 로컬 전용 파일은 배포에서 제외됩니다.
