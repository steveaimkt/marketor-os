# 연결 보드

> 어떤 도구가 연결돼 있는지 한 곳에 적어 둔다. 스킬이 실행 전에 이 파일을 보고 **자동으로 가져올지, 파일을 받을지**를 정한다.
> 상태를 손으로 고쳐도 되고, `node scripts/doctor.mjs` 로 갱신해도 된다.

## 상태

| 도구 | 무엇을 가져오나 | 상태 | 없을 때 |
|---|---|---|---|
| 구글 시트 | 표 데이터 | ⬜ 미연결 | CSV 업로드 |
| GA4 | 세션·전환·채널 | ⬜ 미연결 | `sample-data/A브랜드-채널성과-90일.csv` |
| 파이어크롤 | 웹 수집·경쟁사 감시 | ⬜ 미연결 | 사람이 페이지를 직접 확인 |
| 유튜브 데이터 | 채널·영상 실측 | ⬜ 미연결 | 채널 화면을 보고 수치 입력 |
| 버퍼 | SNS 예약 발행 | ⬜ 미연결 | 완성본을 직접 발행 |
| 메타 광고 | 캠페인·비용·전환 | ⬜ 미연결 | `sample-data/A브랜드-메타광고-30일.csv` |
| 구글 광고 | 검색·디스플레이 성과 | ⬜ 미연결 | 파일 업로드 |
| 노션 | 산출물 아카이브 | ⬜ 미연결 | 로컬 파일로만 저장 |
| 디스코드 | 알림·발송 | ⬜ 미연결 | 사람이 직접 발송 |

## 읽는 법

- **⬜ 미연결** · 자동으로 못 가져온다. 「없을 때」 열의 파일을 쓰거나 사람이 넣는다
- **✅ 연결** · 스킬이 직접 가져온다

**미연결이 기본값이다.** 이 시스템은 연결 없이도 돈다. 연결은 "수동을 자동으로" 바꿀 뿐이다.
연결하는 법은 부록 D에 있다.
