# 워크북 04 · 회사 규칙를 내 업종 규칙으로

> **언제 쓰나** · 본책 5장 「회사 규칙 쓰기」 실습 뒤, 또는 첫 산출물이 내 업종과 안 맞을 때.
> **푸는 문제** · "동봉된 `CLAUDE.md`는 화장품 기준이다. 우리 업종으로 바꾸려면 어디를 고치나."
> **소요** · 10분. 고칠 곳은 다섯 자리뿐이다.

---

## 시작 전에 · 두 파일의 역할이 다르다

| 파일 | 무엇을 적나 | 예 |
|:--|:--|:--|
| `CLAUDE.md` (회사 규칙) | 회사 전체에 적용되는 **규칙** | "산출물 첫 줄에 데이터 출처를 표기한다" |
| `brand/profile.md` (프로필) | 우리 브랜드의 **정보** | "업종: 건강기능식품 · 마진율 42%" |

**업종을 바꾸는 일의 절반은 프로필에서 끝난다.** 게이트가 프로필의 업종 값을 읽어 규제 룰을 자동으로 갈아 끼우기 때문이다. 회사 규칙에서 고칠 것은 규제로 안 잡히는 나머지다.

---

## 고치는 자리 다섯

### ① 업종 값 (프로필)

`brand/profile.md` 의 업종 한 줄. 이 값 하나로 게이트의 검사 규칙 전체가 바뀐다.

```
업종: ____________________
```

**등재된 업종** · 화장품 · 건강기능식품 · 일반식품 · 의약외품·의료기기 · 금융 · (그 외는 표시광고법 공통만 적용)

내 업종이 목록에 없으면 → 아래 ②에서 직접 적는다.

---

### ④ 우리 회사가 안 하는 것 (회사 규칙)

규제와 무관하게 우리가 스스로 정한 선.

| 안 하는 것 | 이유 |
|:--|:--|
| | |
| | |
| | |

> 예: 경쟁사명 언급 안 함 · 공포 소구 안 씀 · 이모지 안 씀 · 할인율 40% 넘게 안 씀.

---

### ⑤ 판정 기준 숫자 (프로필)

리포트가 "좋다/나쁘다"를 가르는 선. 이게 비어 있으면 팀이 기본값으로 판정하고 `[추정]` 태그를 붙인다.

| 항목 | 우리 숫자 |
|:--|:--|
| 마진율 | ____ % |
| 손익분기 ROAS | ____ |
| 목표 ROAS | ____ |
| 월 콘텐츠 발행 목표 | ____ 건 |
| 재구매 기준 기간 | ____ 개월 |

> **손익분기 ROAS는 반드시 직접 계산한다.** 원가에 무엇을 넣느냐(배송비·수수료·포장비·반품률)에 따라 1.6이 되기도 2.4가 되기도 한다. 이 숫자 하나가 틀리면 광고 리포트 전부가 틀린 기준으로 판정한다.

## 고친 뒤 확인

| 확인 | 방법 | 됐나 |
|:--|:--|:-:|
| 게이트가 내 업종 규칙으로 검사하나 | 「이 광고 문제없어?」에 옛 업종 금기어를 넣어 본다 | ☐ |
| 금기어가 실제로 걸리나 | ②에 적은 표현을 카피에 넣어 본다 | ☐ |
| 판정 숫자가 리포트에 반영되나 | 광고 리포트를 돌려 기준선을 본다 | ☐ |
| `[추정]` 태그가 사라졌나 | 산출물 첫 줄을 본다 | ☐ |

---

## 규칙을 늘릴 때와 지울 때

**늘릴 때** · 같은 지적을 세 번째 하고 있으면 회사 규칙에 올린다. 두 번까지는 그날의 사정일 수 있다.

**지울 때** · 반년 동안 한 번도 안 걸린 조항은 아직 필요한지 다시 본다. 추가는 쉽고 삭제는 어렵다. 어려운 쪽이 사람 일이다.

**올리면 안 되는 것** · 시한이 있는 것. 이번 분기만의 사정을 회사 규칙에 올리면 다음 분기에 팀이 틀린 규칙을 성실하게 지킨다.
