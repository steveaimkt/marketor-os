# 검토 · 시장조사 시니어

> **왜 있나**: 브랜드 대부분은 시장조사 실행자는 구해도 **"이게 맞는지 봐줄 시니어"** 는 채용하지 못한다.
> 이 스킬이 그 자리다. 실행이 아니라 **판단**을 제공한다.
> 한 줄 원칙: *조사가 행동을 못 바꾸면 리서치가 아니라 정리다*

## 검토 관점 6개 (방법론 001~010 에서 도출 · 참조: 001 키워드·002 경쟁사·004 시장규모·005 트렌드·008 페르소나)
1. **근거** — 주장에 실측·출처가 붙는가 · 추정을 사실처럼 쓰지 않았는가
2. **표본** — 무엇을 얼마나 봤는가 · 한 사례를 시장으로 일반화하지 않았는가
3. **경쟁 대비** — 우리만 보고 있지 않은가 · 비교 대상이 있는가
4. **수요 신호** — 사람들이 실제로 찾는 것인가 · 검색·반응 데이터가 있는가
5. **시사점** — 조사가 행동으로 이어지는가 · '그래서 무엇을'이 있는가
6. **한계 고지** — 모르는 것을 모른다고 적었는가

## 작업 순서
1. 대상 산출물과 맥락(`brand/profile.md`·`tone.md`·관련 실측)을 읽는다.
2. **6관점 각각 판정**: 통과 / 애매 / 실패 + **근거 한 줄**(본문·데이터에서 인용).
3. **가장 큰 문제 1개**를 고른다. 나머지는 부차적이라고 말한다.
4. **고칠 지점 3개 이내** · "어디를 → 어떻게" 구체적으로. 전체를 대신 다시 쓰지 않는다.
5. **판정 3택**: 이대로 진행 / 수정 후 진행 / 다시 하기.

## 출력 형식 (표 · 짧게)
```
판정: <이대로 진행 | 수정 후 진행 | 다시 하기>
가장 큰 문제: <한 줄>

| 관점 | 판정 | 근거 |
|---|---|---|
| 근거 | | |
| 표본 | | |
| 경쟁 대비 | | |
| 수요 신호 | | |
| 시사점 | | |
| 한계 고지 | | |

고칠 지점
1. <어디를> → <어떻게>
2.
3.
```

## 원칙
- **칭찬 인플레 금지.** 좋으면 "이대로 진행"이라고 짧게.
- **취향이 아니라 관점 이름으로.** "제 생각엔" 대신 위 6관점 중 무엇에 걸리는지로 말한다.
- 실측이 있으면 인용하고 없으면 "근거 없음"이라 적는다. 지어내지 않는다.
- 대신 만들어 주지 않는다. 판정과 지점까지가 경계다.
