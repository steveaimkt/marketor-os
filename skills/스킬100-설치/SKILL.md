# 스킬 100개만 설치하자

> **팀을 짓지 않는다.** 방법론 100개만 쓰는 사람을 위한 길이다.
> 실측: 100개 전부 `agents/`·팀 편성에 의존하지 않는다 (의존 0개). 팀 없이 그대로 돈다.

## 트리거

- "스킬 100개 설치하자"
- "스킬만 쓸래"
- "방법론만 쓰고 싶어"
- "팀은 나중에"

## 경계

| | |
|---|---|
| 이 스킬 | 방법론 100개만 · **팀을 안 만든다** |
| 「팀 구축하자」 | 회사에 맞는 팀을 짓는다 (게이트 6개 · 컨설팅 한 세션) |
| 「설치하자」 | 폴더가 제대로 풀렸는지 진단 (뭔가 안 될 때) |

나중에 팀이 필요해지면 그때 「팀 구축하자」로 가면 된다. **여기서 한 것은 버려지지 않는다.**

## 하는 일 · 네 단계

각 단계 끝에서 결과를 알리고 다음으로 간다. 막히면 거기서 멈추고 대처를 알려준다.

### 1. 있는지 센다

```bash
find 100-skills -name "SKILL.md" | wc -l
```

| 결과 | 어떻게 |
|---|---|
| 100 | 통과. 다음으로 |
| 0 · `100-skills/` 없음 | 폴더가 덜 풀렸다. **「설치하자」** 로 보낸다 |
| 1~99 | 몇 개인지 알리고 **그대로 진행한다** (있는 것만 쓰면 된다) |

부속 3종도 함께 본다. 없으면 알리되 막지 않는다.

| 파일 | 무엇 |
|---|---|
| `100-skills/ROUTING.md` | 어떤 상황에 어떤 스킬인지 |
| `100-skills/compliance.md` | 대외 발행물 규제 검사 |
| `100-skills/gates/` | 게이트 규약 |

### 2. 무엇이 있는지 보여준다

분야 10개 × 10개씩. 표로 짧게.

| 번호 | 분야 | | 번호 | 분야 |
|---|---|---|---|---|
| 001~010 | 시장조사 | | 051~060 | 커머스 |
| 011~020 | 제품기획 | | 061~070 | 데이터분석 |
| 021~030 | 콘텐츠 | | 071~080 | CRM·리텐션 |
| 031~040 | 소셜 | | 081~090 | 브랜드세일즈 |
| 041~050 | 광고 | | 091~100 | 운영 |

### 3. 부르는 법 · 두 가지

**번호로**

```
048 돌려줘
048 랜딩 CRO 진단 해줘
```

**그냥 말로** — 각 스킬의 `triggers` 가 잡는다. 번호를 몰라도 된다.

```
랜딩 전환이 안 나와, 진단해줘        → 048 랜딩페이지 CRO 진단
어느 시장부터 들어가지?              → 010 진입 시장 우선순위
```

어느 스킬인지 모르겠으면 `100-skills/ROUTING.md` 를 읽고 상황에 맞는 것을 고른다.

### 4. 브랜드 정보 · 안 채워도 된다

`brand/profile.md` 를 본다. **여기서 멈추지 않는다.**

- **비어 있다** → 정상이다. 이렇게 알린다.
  "안 채우셔도 다 됩니다. `sample-data/` 로 돌고 산출물에 **[샘플]** 이 붙습니다.
  내 브랜드로 바꾸면 그때부터 **[실데이터]** 가 됩니다."
- **채워져 있다** → 브랜드명·업종을 한 줄로 확인시킨다

100개 전부 `brand/` 를 참조하지만 **의존이 아니다.** 비면 샘플로 돈다.

### 5. 첫 스킬 하나를 같이 돌린다

**설명으로 끝내지 않는다.** 하나를 실제로 돌려 산출물을 보여준다.

무엇을 돌릴지는 사용자에게 묻되, 답이 없으면 `001 키워드 리서치` 로 시작한다
(입력이 가장 적고 결과가 눈에 보인다).

끝나면 산출물 경로와 첫 줄의 출처 태그(`[실데이터]`·`[샘플]`)를 같이 보여준다.

## 규칙

- **팀을 만들지 않는다.** 편성·`brand/my-team.md`·대시보드 배선은 건드리지 않는다
- **없는 것을 있다고 하지 않는다.** 스킬이 100개가 아니면 실제 개수를 말한다
- 산출물 첫 줄 출처 표기는 이 경로에서도 예외 없다 (헌법 「산출물 표준」)
- 사용자가 팀을 원하면 그때 **「팀 구축하자」** 로 넘긴다. 먼저 권하지 않는다

## 막히면

| 증상 | 대처 |
|---|---|
| `100-skills/` 가 없다 | 「설치하자」 로 폴더 상태부터 확인 |
| 스킬을 불렀는데 안 잡힌다 | 번호로 부른다 (`048 돌려줘`) |
| 산출물이 `[샘플]` 로만 나온다 | 정상이다. `brand/profile.md` 를 채우면 `[실데이터]` 가 된다 |
