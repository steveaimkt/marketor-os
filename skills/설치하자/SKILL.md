# 설치하자

> 폴더를 받은 다음 맨 처음 하는 한마디다.
> **설치 절차가 바뀌면 이 파일만 고친다.**

## 트리거

- "설치하자"
- "처음인데 뭐부터 해야 해?"
- "제대로 받았나 확인해줘"
- "팀 받았어"

## 하는 일 · 다섯 단계

각 단계 끝에서 결과를 알리고 다음으로 간다. 막히면 거기서 멈추고 대처를 알려준다.

### 1. 폴더가 제대로 풀렸나

`CLAUDE.md` 가 지금 폴더에 있는지 본다.

- **있다** → 통과. 다음으로
- **없다** → 압축이 한 겹 더 들어간 경우가 가장 많다.
  하위 폴더에 `marketor-os-main` 같은 이름이 있는지 보고, 있으면 **그 폴더를 열어야 한다**고 알린다.

### 2. 무엇이 있나

폴더 지도를 한 번 보여준다. 표로 짧게.

| 폴더 | 무엇 |
|---|---|
| `100-skills/` | 마케팅 방법론 100개 |
| `agents/` | 직원 |
| `skills/` | 내가 만들 것과 팀 도구 |
| `brand/` | 내 회사 정보 |
| `sample-data/` | 실습 데이터 (A 브랜드) |

### 3. 브랜드 정보 상태

`brand/profile.md` 를 본다.

- **비어 있다** → 정상이다. 이렇게 알린다.
  "아직 안 채우셨네요. **그래도 다 됩니다.** `sample-data/` 의 A 브랜드로 진행하고,
  그렇게 만든 산출물에는 `[샘플]` 표시가 붙습니다. 내 브랜드로 바꾸려면 `brand/profile.md` 를 채우면 됩니다."
- **채워져 있다** → 브랜드명과 업종을 한 줄로 확인시킨다

**여기서 멈추지 않는다.** 비어 있어도 다음으로 간다.

### 4. 첫 명령 하나

같이 해 본다. 사용자가 고르게 한다.

```
① 키워드 조사해줘        시장조사팀 · 시드 하나면 시작
② 리뷰 분석해줘          시장조사팀 · sample-data 의 리뷰 200건으로
③ 콘텐츠 캘린더 짜줘     콘텐츠팀 · 한 달 치가 한 번에
```

고른 것을 실제로 실행하고 산출물을 보여준다.
그리고 **방금 무슨 일이 있었는지** 세 줄로 짚는다.

- 프롬프트를 안 배웠는데 결과가 나왔다 (부를 말이 등록돼 있다)
- 팀이 되물었다면 그게 게이트다
- 지어낸 수치에 `[추정]` 이 붙었다면 그것도 게이트다

### 5. 다음에 할 것

```
· 부를 말 전체 목록      100-skills/ROUTING.md  (454개)
· 무엇이 되고 안 되나    node scripts/doctor.mjs
· 팀을 지으려면          "팀 구축하자"
· 화면으로 매일 쓰려면    npm run dashboard
```

## 규칙

- **되묻는 것은 4단계의 선택 하나뿐이다.** 나머지는 확인하고 알려주기만 한다
- 브랜드 정보가 비었다고 멈추지 않는다. 샘플로 진행한다
- 없는 것을 있다고 말하지 않는다. 안 되는 것은 안 된다고 하고 대처를 준다
- 설치를 대신해 주지 않는다. API 키 발급이나 로그인은 사람 몫이다

## 막히면
